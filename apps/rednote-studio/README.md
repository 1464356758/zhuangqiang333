# 笺作 · 小红书内容工作台

手机可用的内容编辑工具。以真实素材为输入，生成可编辑文案和1080×1440文字图卡，手动发布到小红书。

## 访问

[打开笺作](https://rednote-studio-fpq.qq1464356758.chatgpt.site)（创建者私有访问，使用创建时的ChatGPT账号）。

## 已完成
- 本地成稿：6个标题选项、正文、相关话题、图卡；不是模型生成，界面明确标明“本地框架稿”。
- 定位与素材：目标读者、领域、文体、语气、笔记目标、事实、结论、出处、真实经历与商业合作信息。
- 文案编辑、逐页图卡编辑；4个配色，3种版式；加页、删页、排序、署名。
- 单页PNG、整套图卡ZIP、TXT文案、完整发布包导出。ZIP内包含图卡、文案、JSON备份、检查记录和说明。
- 本机自动保存、最多10个草稿版本、JSON导出与恢复。
- 发布前规则检查：绝对化表述、无素材依据的数字、未确认体验、篇幅与图卡容量提示。检查不等于事实认证或平台审核。
- 可选DeepSeek API精修；只在本人点击时发送素材和使用本人API余额；不自动充值或自动重试。
- 无API密钥也可复制专业提示词到现有AI，再导入JSON稿件。

## 手机使用
1. 打开交付的私有网址；使用创建该工具的ChatGPT账号访问。
2. 点击“填写素材”，换成自己的真实事实，点击“本地成稿”。
3. 修改文案和图卡；在“发布检查”导出发布包。解压ZIP，按编号上传PNG并粘贴文案，在小红书内手动发布。

AI精修：点“AI连接”，在自己的DeepSeek官方账户创建API密钥，填入工具，然后点击“AI精修”。密钥不要发给聊天助手。也可无需新充值，复制提示词到已有AI后导入结果。

## 独立维护
Node >=22.13.0，pnpm版本见package.json。
- 安装：`npm run install:ci`
- 测试：`node --test tests/content.test.mjs tests/gateway.test.mjs`
- 类型检查：`node node_modules/typescript/bin/tsc --noEmit`
- 开发：`npm run dev`
- 构建：`npm run build`
- 构建后的本地服务：`npm run start`

Sites环境按DEPLOY.md中的工具流程构建、保存与发布。核心素材与图卡引擎为独立ES模块，不依赖当前聊天。API地址固定，不提供任意转发接口。密钥不放在源码、环境变量、本机存储或导出包。

## 目录
app/page.tsx：编辑器与流程；app/studio.css：桌面/手机样式。
lib/content-engine.mjs：成稿、提示词、结构校验、检查、ZIP。
lib/card-renderer.mjs：实际Canvas排版。
lib/model-gateway.mjs：服务端模型调用和异常处理。
lib/project-storage.mjs：备份白名单，排除连接密钥。
tests/：本地及接口测试。
