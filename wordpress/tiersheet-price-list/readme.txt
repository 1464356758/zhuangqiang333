Create a complete price list from your product CSV, locally in your browser.

== Description ==

Use Tools > TierSheet Price List to choose a UTF-8 CSV, map SKU/name/unit-price columns, preview your list and download PDF, CSV or HTML output.

Every included function is free. There is no account, expiry, licence key or row-based payment lock. The app performs no telemetry, uploads or store changes. It does not fetch your store catalog or automatically send files to customers.

Technical memory bounds: 25 MB input, 20,000 product records, 100 PDF pages. PDF pages are image based at 150 DPI. For long names or larger PDFs, use CSV/HTML. Full supported product rows are included in output; the screen preview displays up to 60 rows.

The project separately develops a batch price-tier tool outside this free plugin. Sales are not open during functional validation. No batch-edition or activation code is bundled.

== Installation ==

1. Upload the complete generated plugin ZIP using Plugins > Add New > Upload Plugin.
2. Activate, then open Tools > TierSheet Price List.
3. Choose CSV, review the mapped price source and input notices, and export.

== Frequently Asked Questions ==

= Does my CSV leave the browser? =
No. The app reads files in tab memory and creates downloads locally. Its CSP disallows network connections.

= Do I need WooCommerce? =
No. Any product CSV with SKU, name and a decimal unit price can be used. WooCommerce export columns can be mapped manually.

= What prices are included? =
The selected price column. No currency conversion, tax determination or store/customer-pricing lookup is performed.
